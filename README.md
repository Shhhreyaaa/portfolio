# ⚡ SHREYA | Creative Developer Portfolio

A premium, highly interactive personal portfolio website styled with custom glassmorphism, dynamic transitions, and a cinematic theme. Fully optimized for responsiveness across mobile, tablet, and desktop viewports.

👉 **Live Demo:** [shreyasomi.vercel.app](https://shreyasomi.vercel.app) | [shreyasomi.me](https://shreyasomi.me)

---

## ✨ Features

* 🎬 **Cinematic Preloader:** Captivating character-by-character letter loader with subtle glow animations on page load.
* 🌌 **Fluid Gradient Background:** High-performance, GPU-accelerated rotating gradient background using the Attitude color palette (`#FFDBE8`, `#FF94B2`, `#F24455`, `#E5203A`).
* 🌓 **Responsive Theme Toggle:** Seamless dark/light theme switching with automated backdrop-filters and contrast-aware overlays.
* 🛠️ **GitHub Contributions Heatmap:** Custom-styled interactive contribution graph showing development stats.
* 💬 **Companion Chat Bot:** Embedded interactive chat assistant widget with a friendly conversational interface.
* 📱 **Perfect Mobile & Tablet Flow:** Built using dynamic viewport units (`100dvh`, `vmax`) and clip bounds to prevent accidental horizontal scrolls or content cutoff.

---

## 🚀 Tech Stack

* **Structure:** Semantic HTML5
* **Styling:** Custom Vanilla CSS3 (Custom Variables, Composited Transforms, Glassmorphism, Backdrop Filters)
* **Interactions & Logic:** ES6+ JavaScript
* **Icons:** Lucide Icons
